YOUR OWN HORSE PHOTOS — they replace the stock photos in "Meet our horses"

Name each photo after the horse it shows (lower case; spaces become hyphens):
  willow.jpg   peanut.jpg   storm.png   sea-biscuit.webp

Starter horses: peanut, biscuit, pebbles, coco, willow, sage, honey, storm, coral,
sandy, misty, shadow, breeze, blaze, tide, atlas, duke

Formats: .jpg .jpeg .png .webp   Tip: about 1200 px wide and under 500 KB each.
A horse you add yourself in Admin → Horses uses its own name the same way.
Photos in this folder are part of the website code, so they stay on the live site
(upload them to GitHub in static/img/horses/own/). Photos uploaded in Admin → Horses
take priority over these, but on a free Render server they are lost when it restarts.
